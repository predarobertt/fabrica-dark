FABRICA DARK

Industrial Manufacturing Data Platform

Fabrica Dark is a portfolio project focused on collecting, processing, analyzing and visualizing synthetic manufacturing data form an injection molding factory.

THe project combines industrial engineering knowledge with data engineering technologies to demonstrate how production data can support operational decisions.

Project Overview

The platform simulates a plastic injection molding factory with:

- 5 injection molding machine
- 30 manufactured products
- 5 years of synthetic production history
- Production cycle time target: 50 seconds (±2 seconds)

All date is synthetic and created for educational and demonstration purposes.

Main Modules

1. Production

- Machine performance monitoring
- Production quantities
- Cycle time analysis
- Production efficiency and OEE indicators

2. Quality

- Quality inspection data
- Defect tracking
- Scrap rate analysis
- Quality performance indicators

3. Mold Management

- Mold and cavity tracking
- Mold lifetime monitoring
- Maintenance and intervention history
- Service and wear analysis

Project Objectives

- Build a structured industrial data platform.
- Develop data engineering skills using a realistic manufacturing scenario.
- Apply Python and SQL to production data.
- Create meaningful operational indicators and visualizations.
- Demonstrate the connection between manufacturing engineering and data engineering.

Technology Stack

The technology stack will be expanded as the project develops

- Python
- SQL
- Git and GitHub
- PostgreSQL (planned)
- Data visualization tools (planned)

Project Status

Early development - Initial project structure created.

More functionality, documentation, tests and datasets will be added progressively.

Data Policy

All datasets are synthetic. No confidential company or production data is used.
